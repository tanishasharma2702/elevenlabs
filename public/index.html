ElevenLabs API Setup & Instructions

AI Voice Narrator uses a secure Netlify serverless backend to keep your API key 100% private. Follow these quick steps to get connected:

1
Get your API key

Sign up or log in at elevenlabs.io, go to Profile Settings > API Keys, and copy your key.

2
Local Testing (.env)

Create a file named .env in the project root folder with:

ELEVENLABS_API_KEY=your_actual_key_here

Then run npm run dev or npx netlify dev.

3
Netlify Deployment

In your Netlify Site dashboard, go to Site Configuration > Environment Variables, add ELEVENLABS_API_KEY, and save.

Security Guarantee: Your key is never sent to the browser or stored in source code. All TTS requests run securely through the Netlify Functions backend.
